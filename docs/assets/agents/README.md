# External agent identification marks

These marks identify the external-agent examples in the workspace section. The Codex entry uses OpenAI's black Blossom; the DeepSeek Harness entry uses the DeepSeek provider mark, rather than asserting a separate Harness product identity. Original proportions and colors are retained; ICO images are decoded to PNG for browser compatibility.

The marks and names belong to their respective owners. Their display identifies compatible external tools and does not imply a partnership, sponsorship or endorsement. They are not part of OceanStudio's own branding and are not relicensed as OceanStudio artwork.
